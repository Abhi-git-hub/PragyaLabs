# User journey — intrigue to inquiry

| # | Chapter | Visitor feels | CTA + purpose |
|---|---|---|---|
| 0 | Entry / preloader | Anticipation, no wait | None — lifts in ≤1.5s |
| 1 | Hero / Signal Chamber | Intrigue — "not a normal agency" | Start a project (primary) / Explore selected work (secondary) |
| 2 | Recognition | Recognition — "they understand my mess" | None — problem resonance |
| 3 | Transformation | Orientation — fragments can converge | Continue to capabilities |
| 4 | Capability worlds | Clarity — "I see what they build" | Explore AI / web / interactive (service pages) |
| 5 | Method | Confidence — "low risk, clear path" | None — risk reduction |
| 6 | Proof | Trust — "real work, honestly labeled" | Open case per card (dossiers) |
| 7 | Engineering wall | Respect — "one engineer, full chain" | None — depth signal |
| 8 | Editorial relief | Calm — "thoughtful, not hype" | None — exhale |
| 9 | Founder | Accountability — "I know who builds" | About the studio / GitHub |
| 10 | Final | Action — "starting is easy" | Send project context (form) |

Rule: CTAs appear at hero (start), capability (explore), proof (open cases), final (send). Never popups, never fake urgency.
